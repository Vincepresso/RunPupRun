## 📖 About The Project

**RunPupRun** is an action-packed platforming runner where quick reflexes are key. Help your pup dash through vibrant environments, leap over dangerous hazards, collect treats, and push for the highest score possible.

### Core Concept
- **Run & Jump:** Time your jumps, double jumps, and dashes to clear obstacles safely.
- **Collectibles & Score:** Gather treats and power-ups scattered along the track to maximize your run score.

---

## ✨ Features

- ⚡ **Fluid Movement:** Snappy jump mechanics, gravity tuning, and responsive controls.
- 🎯 **Dynamic Obstacles:** Spikes, pits, and moving hazards to challenge your timing.
- 🦴 **Pickups & Power-ups:** Collect treats to boost score and unlock temporary abilities.
- 🎨 **Charming Visuals & FX:** Playful animations, screen shake, and particle effects.

## 🚀 Getting Started (For Developers)

Follow these instructions to get a local copy up and running for development or testing.

### Prerequisites

- [Godot Engine 4.x](https://godotengine.org/download) installed on your system.
- Git for repository management.

### Installation & Setup

1. **Clone the Repository**
   ```bash
   git clone [https://github.com/Vincepresso/RunPupRun.git](https://github.com/Vincepresso/RunPupRun.git)
   cd RunPupRun
   ```

2. **Open in Engine**
   - Open Godot Engine.
   - Click **Import** and navigate to the cloned project folder.
   - Select the `project.godot` file and click **Import & Edit**.

3. **Run the Project**
   - Press `F5` (or click the Play button in the top right corner) to launch the main scene.

## 🎮 Game Controls

| Action | Keyboard | Controller |
| :--- | :--- | :--- |
| **Jump / Double Jump** | `Space` / `W` / Up Arrow | `South Button` / `A` |
| **Slide / Duck** | `S` / Down Arrow | `RT` / Down Analog |
| **Dash / Action** | `Shift` / `E` | `West Button` / `X` |
| **Pause** | `Esc` | `Start` |
